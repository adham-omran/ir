#+date: 2026-06-01
#+startup: content

* Status
Specced, not implemented. Target: 0.14.0. Destructive (deletes files), so
confirmation + the file-vs-heading branch are non-negotiable.

* Goal
=(ir-done-and-delete)= removes the item at point from both disk and the queue,
choosing delete-file vs delete-subtree by node shape, with an informed
confirmation.

* Decisions locked
| Fork                 | Resolution                                                            |
|----------------------+-----------------------------------------------------------------------|
| Heading items        | cut the subtree (=org-cut-subtree=) + delete row; keep the file       |
| File-level nodes     | delete the file                                                       |
| Trash vs permanent   | OS trash (recoverable); =ir-delete-to-trash= default t                |
| "done" record        | append timestamp/title/id to =ir-done-log-file= before deleting       |
| Collateral           | inform-then-proceed (no abort): confirmation shows counts             |
| Backlinks            | disclose incoming-link count; do NOT auto-repair foreign files        |

* Confirmed mechanics (research)
- File-vs-heading detection: =org-before-first-heading-p= (same predicate as =ir--narrow-to-item=).
- id -> file: =org-id-find-id-file= / =org-roam-node-file=.
- Delete file: =delete-file= (TRASH arg for trash); org-roam advises =delete-file :before= (=org-roam-db-autosync--delete-file-a=, org-roam-db.el:651) so the roam db self-cleans when autosync is on; else =org-roam-db-clear-file=.
- Cut a heading: =org-cut-subtree= (lands in kill-ring, recoverable via yank).
- Incoming references: =org-roam-backlinks-get= (org-roam-mode.el:481) / =links= table =dest= column — a db query, no file I/O.
- =delete-by-moving-to-trash= defaults nil -> =delete-file= is permanent unless TRASH is passed.

* Contract
- pre: point in an Org buffer, on/within a queued item (=ir--id-at-point= in db).
- post: completion logged; the unit's db row(s) gone; file-level -> file in trash; heading -> subtree cut (file kept); roam db + buffer consistent; foreign backlinks disclosed (left dangling).
- invariant: no deletion without an informed confirmation; a heading item never deletes a file.
