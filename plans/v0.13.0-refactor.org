- F1 [confirmed] Topic next interval = =interval × A-Factor=. (super-memory.com/help/g.htm)
- F2 [confirmed] Priority 0% = most important, 100% = least; lower = sooner. (g.htm; help.supermemo.org/wiki/Priority_queue)

** 4 Scheduling algorithm (faithful SuperMemo topic)
- [ ] 4.1 =MUST= =ir--reschedule(id)= in one transaction:
  - =elapsed = max(1, round((now − last_reviewed) / 86400))=
  - =interval' = max(1, round(elapsed × afactor))=
  - =afactor' = afactor + ir-afactor-increment=
  - =due' = now + interval' × 86400=; =last_reviewed' = now=
  Verify: afactor 2.0, last_reviewed 20d ago, reviewed today → interval'=40, due'≈now+40d, last_reviewed'=now.
- [ ] 4.2 =SHOULD= =interval= is informational (not an algorithm input under D-4); it is the manual-reschedule knob. Editing =interval= ⇒ =due = now + interval × 86400=; editing =due= sets it directly. Verify: set interval=7 → due = now+7d.
- Known properties (not bugs): early review (now<due) → smaller elapsed → smaller next interval; first review of an import treats import time as pseudo-last-review.
- [ ] 4.3 =MAY= priority→first-interval (SuperMemo derives first interval from priority). Deferred.
